# Datathon Project

## 🚀 Quick Start
1. Create environment: \`python -m venv .venv\`
2. Activate: \`source .venv/bin/activate\` (Unix) or \`.venv\Scripts\activate\` (Win)
3. Install: \`pip install -r requirements.txt\`

## 📁 Project Structure
- \`data/raw\`: Original, immutable data dumps.
- \`data/processed\`: Cleaned data ready for modeling.
- \`notebooks/\`: Exploratory Data Analysis (EDA) and prototyping.
- \`src/\`: Modularized code for training and inference.
- \`models/\`: Saved model weights and pickles.
